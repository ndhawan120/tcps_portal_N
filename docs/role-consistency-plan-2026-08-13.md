## Shared navigation
- Dashboard
- Exams
- PER Objectives
- Updates
- Profile

## Employee
- Documents
- No manager/admin controls

## Manager
- Team
- Approvals
- Reports (team-scoped)

- People
- Approvals

- Admin

- Same Material Symbols icon treatment
